# 令和8年熊本地震｜取引校 対応状況ダッシュボード

教育と探求社の**九州の取引校（特に熊本県の中高）**について、令和8年（2026年）熊本地震（2026/07/28 16:27・M7.1・最大震度7）の影響を地図上にプロットする単一HTMLアプリです。地図は **Leaflet + OpenStreetMap**（APIキー不要）で描画するため、**GitHubに置くだけで動作**します。

## 使い方（ローカル確認）

`index.html` をブラウザで開くだけです。ビルド不要・インターネット接続のみ必要（地図タイルとLeaflet CDNを読み込みます）。

## GitHub Pages での公開手順

1. GitHubで新規リポジトリを作成（例：`kumamoto-eq-schools`）。
2. このフォルダの `index.html`（と `README.md`）をアップロード（またはpush）。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment → Source** を **Deploy from a branch** に設定。
5. **Branch** を `main` / フォルダ `/(root)` に指定して **Save**。
6. 数十秒〜数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

> `index.html` はリポジトリ直下に置いてください。サブフォルダに置く場合はそのパスでアクセスします。

## 機能

- 顧客校を **震度ベースの「要確認度」** で色分けしたピンで表示（★は熊本県内校）。
- 参考として **震源・主な被害地点**（宇城市・氷川町・八代市・イオンモール熊本・益城町）を四角マーカーで表示。
- ピンのポップアップに **住所・電話番号・震度・状況・出典リンク** を表示。電話番号は `tel:` リンクで発信可能。
- 左サイドバーに **KPI・凡例・フィルタ・顧客校一覧**（クリックで地図移動）。
- フィルタで「顧客校のみ」「熊本県のみ」等の切り替えが可能。

## データについて（重要）

- 本アプリは**発災翌日（2026/07/29 時点）の暫定情報**です。
- 各校の**安否・授業・被害は、公式発表が確認できたものだけ**を記載しています。未確認は「**確認中**」と明記し、推測での断定はしていません。
- ピンの色は**気象庁の市町村別震度から推定した「要確認度」**であり、実際の被害の有無を示すものではありません。
- **熊本県外の九州各校の座標は市の代表点（目安）**です。連絡先・状況は各校公式でご確認ください。
- 熊本県内の重点3校（クラーク記念国際高校 熊本キャンパス／熊本県立熊本商業高校／九州看護福祉大学）は住所・電話番号を確認済みです。

## 自動更新（2時間ごと）

`kumamoto-eq-school-status-crawl` という定期タスクが **2時間ごと（毎偶数時00分）** に以下をクロールし、`index.html` の `FEED` ブロックと各校の `status` を更新します。

**クロール対象**

| 区分 | 情報源 |
|---|---|
| 学校公式 | クラーク熊本キャンパス、熊本商業高校、九州看護福祉大学 |
| 行政・教委 | 熊本市 令和8年熊本地震 特設ページ、熊本県 災害対策本部、熊本県教育委員会、気象庁 |
| note | note.com（本文取得可） |
| X | WebSearch経由でタイトル・スニペット・URLのみ取得 |
| 報道 | NHK、熊本日日新聞、RKK、KKT、KAB、日経 |

**自動更新のルール（タスクに組み込み済み）**

- 公式発表が確認できた事実のみ `status` に反映。未確認は「確認中」のまま。
- SNS由来は `src:'SNS'` として**未確認情報**扱い。マーカーの確定ステータスには反映しない。
- 生徒・保護者などの個人投稿は、**個人が特定される内容を転載しない**（傾向の記述にとどめる）。
- 2016年（平成28年）熊本地震のアーカイブ資料と混同しないよう日付を必ず検証。
- 更新後に `node --check` でJS構文を検証。

**注意点**

- 定期タスクは**このアプリが起動している間**に実行されます。閉じている間に予定時刻を過ぎた場合は、次回起動時に実行されます。
- **X（Twitter）は直接のページ取得がブロックされます**。検索結果のタイトル・スニペット・リンクのみを扱う設計です。
- 初回は「今すぐ実行」を押してツール権限を承認しておくと、以降の自動実行が権限待ちで止まりません。

## データ更新方法

`index.html` 内の `const DATA = [ ... ]` 配列を編集してください。各校の項目：

| フィールド | 内容 |
|---|---|
| `type` | `'client'`（顧客校）/ `'ref'`（参考被害地点） |
| `name` / `cat` | 校名 / 種別 |
| `pref` / `city` / `addr` | 都道府県 / 市区町村 / 住所 |
| `tel` | 電話番号（空文字なら「要確認」表示） |
| `lat` / `lng` | 緯度 / 経度 |
| `intensity` | 表示用の震度文字列 |
| `band` | 色分け用（7 / 6.5=6強 / 6=6弱 / 5.5=5強 / 5=5弱 / 4 / 3） |
| `precise` | `true`=住所ベース座標 / `false`=市の目安座標 |
| `status` / `statusNote` | 状況（確認できた公式情報のみ） |
| `sources` | 出典リンク配列 `[{t:表示名, u:URL}]` |
